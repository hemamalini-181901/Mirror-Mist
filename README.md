# 🌫️ FOG MIRROR

**An interactive digital mirror inspired by the magic of fog on glass.**

🔗 **Live Demo:** https://tranquil-sorbet-366d12.netlify.app/

## ✨ About the Project

FOG MIRROR is a browser-based creative project that explores a fogged-glass mirror experience through interactive visual effects and hand gestures.

## 🚀 Features

- Dreamy blue and lavender interface
- Interactive fog and glass-clearing effects
- Webcam-based visual interaction
- Hand gesture recognition using MediaPipe
- Microphone-based breath-inspired interaction
- Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas
- MediaPipe
- Web Camera and Microphone APIs

## ▶️ Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run a local development server, such as:

   ```bash
   python -m http.server 8000
   ```

4. Open http://localhost:8000 in your browser.
5. Allow camera and microphone access when prompted.

## 🔒 Privacy

Camera and microphone access require user permission. Review the implementation to confirm how media is processed before making privacy claims.
